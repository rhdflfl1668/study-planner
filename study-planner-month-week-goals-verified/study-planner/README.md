# 차곡차곡 — 달력 중심 스터디 플래너

아이보리·세이지 그린 테마의 모바일 우선 React 웹앱입니다. 연간 화면은 1~12월 미니 달력을 한눈에 보여주고, 월간 달력은 날짜별 공부 과목과 완료 상태를 표시합니다. 일간 화면에서는 과목, 공부 목표, 메모를 기록하고 목표 완료 여부를 체크할 수 있습니다.

## 포함 기능
- 연간 화면: 1월부터 12월까지 달력 12개를 한 화면에 표시
- 연간 달력에서 날짜별 기록 유무와 완료 상태를 간단히 표시
- 월간 달력에서 날짜별 공부 과목과 목표 완료 상태 표시
- 날짜를 선택해 일간 기록 화면으로 이동
- 일간 공부 항목 추가/수정/삭제, 과목, 메모, 완료 체크
- 월간 화면에서 해당 월의 목표를 입력하고 확인
- 일간·월간 화면에서 선택한 날짜가 포함된 주의 주간 목표를 입력하고 확인
- 목표는 미리보기 모드에서 이 브라우저에 저장되며, Supabase 연결 시 클라우드 동기화 가능
- 공부시간 기록 및 타이머 없음
- 월별·연간 달성률 및 공부시간 목표 통계 없음
- Supabase 이메일 로그인/회원가입 및 클라우드 저장 코드
- Supabase 미설정 시 UI 미리보기 모드
- 아이폰 Safari 화면, 하단 내비게이션, 홈 화면 웹앱 메타 태그 대응

## 실행 방법
1. Node.js LTS를 설치합니다.
2. 이 폴더에서 터미널을 열고 `npm install`을 실행합니다.
3. `npm run dev`를 실행합니다.
4. 터미널이 표시하는 로컬 주소를 브라우저에서 엽니다.

## Supabase 연결 방법
1. https://supabase.com 에서 프로젝트를 만듭니다.
2. Supabase Dashboard의 SQL Editor에서 `supabase/schema.sql` 전체를 실행합니다. 월간·주간 목표 저장을 위해 `study_period_goals` 테이블도 생성됩니다.
3. 프로젝트의 API 설정에서 Project URL과 publishable/anon key를 확인합니다. `service_role` 또는 secret key는 절대로 브라우저 앱에 넣지 마세요.
4. 프로젝트 루트의 `.env.example`을 복사해 `.env`로 저장하고 다음 값을 입력합니다.
   - `VITE_SUPABASE_URL=...`
   - `VITE_SUPABASE_ANON_KEY=...` (대시보드에서 제공하는 브라우저용 publishable/anon key)
5. 개발 서버를 재시작합니다.
6. 계정 버튼에서 회원가입/로그인합니다. 이메일 확인이 켜져 있다면 메일 확인을 완료해야 할 수 있습니다.

## 아이폰에서 사용
- 개발 중에는 컴퓨터와 아이폰이 같은 Wi-Fi에 있을 때 Vite가 표시하는 네트워크 주소로 접속할 수 있습니다. 방화벽 설정이 필요할 수 있습니다.
- 실제 일상 사용을 위해서는 HTTPS가 적용된 호스팅(예: Vercel 또는 Netlify)에 배포하세요.
- 배포 주소를 iPhone Safari에서 열고 공유 버튼 → **홈 화면에 추가**를 선택합니다.
- 이 단계는 홈 화면에서 실행되는 웹앱입니다. App Store에 올리는 네이티브 앱과는 다릅니다.

## 참고
- Supabase가 설정되지 않은 미리보기 모드에서는 실제 클라우드 저장이 활성화되지 않습니다.
- 기존 데이터베이스의 공부 시간 관련 열은 호환성을 위해 남아 있지만, 앱 화면에서는 입력하거나 표시하지 않습니다.

## 아이폰에 앱처럼 설치하기 (PWA)
이 프로젝트는 아이폰에서 홈 화면 앱처럼 실행할 수 있는 PWA 설정을 포함합니다. ZIP을 아이폰에 복사하는 것만으로는 설치되지 않으며, 먼저 HTTPS 웹 주소로 배포해야 합니다.

1. 프로젝트를 GitHub 저장소에 올리거나, 컴퓨터에서 Vercel/Netlify로 배포합니다.
2. 배포가 끝나면 `https://...` 형태의 주소를 확인합니다.
3. 아이폰에서 **Safari**로 그 주소를 엽니다.
4. 공유 버튼 → **홈 화면에 추가** → 추가를 누릅니다.
5. 홈 화면의 **차곡차곡** 아이콘을 눌러 앱처럼 실행합니다.

`public/manifest.webmanifest`, 앱 아이콘, 서비스 워커가 포함되어 있습니다. 오프라인 캐시는 앱 화면을 다시 여는 데 도움을 주지만, Supabase 클라우드 저장/로그인에는 인터넷 연결이 필요합니다. Supabase를 설정하지 않은 미리보기 모드는 다른 기기와 데이터가 자동 동기화되지 않습니다.

### App Store 앱과의 차이
PWA는 App Store에서 검색해 내려받는 네이티브 앱이 아니라, 웹 주소를 Safari에서 홈 화면에 추가하는 방식입니다. App Store에 등록하려면 별도의 iOS 앱 패키징, Apple 개발자 계정, macOS/Xcode 빌드 및 심사 과정이 필요합니다.
